# Портфолио Саши Литовой

Готовый статический сайт с адаптацией для телефонов. Сборка и установка программ не требуются.

## Что загрузить на GitHub

Распакуйте архив. Откройте папку litova-github и загрузите её содержимое в корень репозитория:
- index.html — страница, стили и интерактивность;
- assets — все изображения;
- .nojekyll — служебный файл для GitHub Pages;
- README.md — эта инструкция.

Важно: index.html должен находиться в корне репозитория, рядом с папкой assets. Не загружайте ZIP вместо распакованных файлов и не переименовывайте папку assets.

## Публикация на GitHub Pages

1. Создайте публичный (Public) репозиторий, например litova-portfolio. GitHub Pages доступен бесплатно для публичных репозиториев.
2. На вкладке Code выберите Add file → Upload files. Перетащите index.html, папку assets и README.md из распакованной папки. Сохраните загрузку кнопкой Commit changes. Файл .nojekyll может быть скрыт на компьютере: его можно создать через Add file → Create new file, указав имя .nojekyll и сохранив пустой файл.
3. Откройте Settings → Pages.
4. В Build and deployment выберите Source → Deploy from a branch.
5. Выберите ветку main, папку / (root), нажмите Save.
6. Дождитесь публикации. В Settings → Pages появится ссылка и кнопка Visit site. Публикация может занять до 10 минут.

Адрес будет вида https://ВАШ-ЛОГИН.github.io/litova-portfolio/ — точный адрес скопируйте из Settings → Pages.

Инструкция GitHub: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Просмотр на компьютере

Откройте index.html двойным щелчком. Папка assets должна оставаться рядом.

## Редактирование

Тексты, стили и скрипты находятся в index.html, изображения — в assets. После правок загрузите изменённые файлы в ту же ветку GitHub. Публикация обновится автоматически.
